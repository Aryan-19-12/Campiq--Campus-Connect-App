# Campiq Master Merge (v1)

This project merges the four AI Studio export batches into one React/Vite application.

## Included
- Batch 1: core shell, Home, Explore, Help, Profile, routing/PWA shell
- Batch 2: Food & Crowd, Events, Clubs, Opportunities, Lost & Found, Teams, Skill Exchange + details
- Batch 3: Community + post detail components (sanitized for the master route)
- Batch 4: Messages and Notifications components (sanitized for the master route)
- Clean Settings & Privacy page aligned to the Campiq scope
- Safe Help detail page

## Intentionally not wired yet
- Real Ask Campiq AI (`/ask` is still a placeholder)
- Real campus map/navigation (`/navigation` is still a placeholder)
- Backend/Supabase/auth/realtime
- Batch 3 emergency SOS / guard dispatch / hotline flows
- Batch 3/4 digital student ID, roll number, hostel-room, live-location and ERP-like UI

Those excluded items were generated by AI Studio but conflict with the intended Campiq product scope.

## Run
```bash
npm install
npm run dev
```

## Validate
```bash
npm run lint
npm run build
```
